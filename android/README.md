# APK Meu Ponto

Este APK é um contêiner Android WebView para o Meu Ponto publicado no GitHub Pages.
Os registros são armazenados no WebView do aplicativo, separados dos dados do Chrome.
É necessário acesso à internet para a primeira abertura; não há widget Android nativo.
Notificações da página não são garantidas no WebView, especialmente com o app fechado.

## Compilar sem computador
GitHub > Actions > Gerar APK Meu Ponto > Run workflow.
Depois abra a execução concluída e baixe o artifact **MeuPonto-APK**.
Extraia o ZIP para obter app-debug.apk e instale no Samsung.

O APK de debug é para uso pessoal/testes, não para distribuição em loja.
